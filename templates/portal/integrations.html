Software service accounts

Local non-human identities used by Cretan Staffing integrations. They are separate from WordPress, which is intentionally excluded.

This registry does not create accounts with external vendors or generate API keys. Each provider connection still requires authorized setup and credentials stored as environment secrets.

External software connections

These are planned provider connections, not claims that vendor accounts have already been created.
